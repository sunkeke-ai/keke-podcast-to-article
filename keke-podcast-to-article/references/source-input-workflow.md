# YouTube与小宇宙输入

1. 识别单集，核实标题、人物与来源。链接带起始时间不自动表示只整理该时间之后，除非用户指定范围。
2. 优先用户本地原稿，其次平台字幕/文字稿，再次可核验公开逐字稿。记录来源、语言、时间戳与覆盖范围。使用可用连接器、浏览或转写能力，不能假设平台必有字幕或可下载音频。
3. YouTube优先真实字幕；小宇宙检查单集页、完整文字稿及可访问音频。有合法可访问音视频且有转写工具时再转写，长材料分段后核对衔接。访问受限、缺少音频或无工具时说明具体缺口，请用户提供文字稿或可访问音视频，不承诺任意链接都能转写。
4. 只有简介或不完整字幕时明确覆盖范围，不生成貌似完整的长文和缺失内容的配图。不用未读的第三方摘要替代原稿。尊重来源使用限制，用户原稿与外部网页分别处理。

通读原稿后按主Skill整理中文文章，英文引文标为译文；保留来源链接和工作稿定位，职位、产品计划与观点按录制时点归因。默认交付文章与第一正文章节完整内容配图（3:2，极简视觉隐喻风），等用户确认后完成其余各章节。

Obsidian保存遵循 [obsidian-export.md](obsidian-export.md)，公开Skill与本机私人配置分离，不沿用上一篇文件名或日期。
